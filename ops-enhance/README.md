# AntSpy Ops · 运营后台增强

基于 `ops-quota-2.2` / 1.9.2 的运营后台原型，对齐《AntSpy 运营后台增强 PRD》演示。

## 打开

浏览器打开 `index.html`。

## 相对基线新增

| 模块 | 内容 |
| --- | --- |
| 运营概览 | 官网漏斗（访问 / 点注册 / 完成注册 / 完成搜索）、转化率、活跃人数、总消耗分项、每日 DAU 趋势 |
| 客户管理 | 原「商户管理」；列表增加来源、额度摘要；详情增加来源与「今日行为」时间线 |
| 变更记录 | 交互与字段保持现状，仅展示文案「商户」→「客户」 |

## 建议体验路径

1. 运营概览：切换日期范围，看漏斗与 DAU 联动。
2. 客户管理：按来源筛选；点开 Northstar Commerce → **今日行为**。
3. 变更记录：确认列表与筛选行为与旧版一致。
